# 12: Additional language localization

**What to build:** A user can switch language to at least one newly supported language, and every screen in the app reads in that language.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] At least one additional language is added to the string catalog with full translations for all existing keys
- [ ] Switching device language to the new language renders every screen (auth, Home, Records, Reports, More, Profile, etc.) in that language, with no leftover English strings
- [ ] Number/date/currency formatting remains correct for the new locale
