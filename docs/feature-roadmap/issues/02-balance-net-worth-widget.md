# 02: Balance/Net Worth Home Screen widget

**What to build:** A user adds a Home Screen widget showing their live balance and net worth; tapping it opens the app to Home.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] A widget extension target exists and ships a small/medium widget showing balance this month and net worth
- [ ] The widget's data refreshes periodically without requiring the app to be foregrounded
- [ ] Tapping the widget deep-links into the Home screen
- [ ] The widget renders correctly in both light and dark mode
