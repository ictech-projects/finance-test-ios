# 11: Spotlight search for transactions/accounts

**What to build:** A user searches system Spotlight for a transaction description, merchant, or account name, finds it in the results, and tapping it opens the app to that item.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] Transactions and accounts are indexed for Spotlight as they're created/updated, and removed from the index when deleted
- [ ] Searching Spotlight for a known transaction description/merchant or account name surfaces it
- [ ] Tapping a Spotlight result deep-links into the corresponding transaction/account in the app
